# 游戏内行为

[English](../en/behavior.md) · [入门](getting-started.md) · [API 参考](api.md)

PackmasterLib 在游戏中的行为，以及卡包需要遵守的规则。除特别说明外，均与 1 代 The Packmaster 一致。

## 选人界面：卡包配置

选中卡包角色后，右上角出现**卡包配置面板**（点标题可折叠）：

- **全卡包**：所有已解锁卡包都进入本局，不选包（1 代全卡包模式）。
- **卡包数量**：3–10 个槽位。
- 每个槽位：**随机**、**三选一**、**无**或指定卡包。

配置按角色保存在 `user://PackmasterLib/config.json`。玩家修改之前使用角色的 `DefaultSlots`；多人模式始终使用 `DefaultSlots`。

除非开启「允许多个"无"槽位」，否则只有第一个「无」生效，其余改为随机卡包。

## 开局：槽位解析

开局时：

1. **指定**槽取得对应卡包（未知、未解锁或重复的跳过）。
2. **随机**槽从尚未取得的已解锁卡包中抽取（`Drawer.DrawRandomSlot`）。
3. **三选一**槽只计数，每个对应选包界面中的一轮。

所有随机都基于本局种子，相同的种子和配置得到相同的卡包。

## 选包界面

进入第一个房间、涅奥之前弹出：

- 上方：**已选定卡包**——指定和随机槽的卡包。
- 中间：**选择一组卡包来将其加入本局游戏的牌池！**——本轮候选（`ChoiceSize`，默认 3）。
- 悬停卡包显示**卡包概要**（星级评分和标签）；卡下方显示作者。底部居中的「显示卡包评分」可隐藏星级。
- 左下角**返回**按钮或 **Esc**：收起界面查看涅奥或地图，再按一次回到选包界面。确认前点击涅奥选项或地图节点会直接回到选包界面。
- 全部轮次选完后卡包居中排列，点**确认**继续。涅奥的选项不受影响。

**确认前可以 SL**：确认之前的选择只在内存中，不写入存档。读档后从头选，相同的选择会得到相同的候选。

全卡包模式、多人模式（按种子确定性决定）和开发选项「跳过选包」下不显示此界面。

### 候选规则

每轮从「有预览卡、已解锁、尚未进入本局」的卡包中提供候选。

- **默认（1 代）**：提供过但没选的卡包在耗尽前不再出现。剩余的新卡包不足 `ChoiceSize` 时，用跳过的卡包补足。
- **开发选项「宽松选包」**（`ExcludeOnlyLastRound`）：只有上一轮未选的卡包在本轮不出现，隔一轮可再出现。

候选按（本局种子、玩家、轮次、已选卡包）延迟且确定性地生成。只有在没有卡包可选时候选才为空。

## 本局卡池

角色的卡池是**已选卡包的卡**加上 `ExtraPoolCardTypes`：

- 卡牌奖励、商店、事件、药水和各种「随机一张牌」效果只使用已选卡包；
- **变化**只在本局卡包内进行（无色牌照旧变为无色牌）；
- 尘封魔典从 `ExtraPoolCardTypes` 中挑选先古牌；
- 卡包中的原版卡保留原卡框，开启「统一卡框」后除外。

所以卡包需要足够的深度，见[入门](getting-started.md#9-卡包设计规则重要)中的卡包设计规则。

## 卡面

属于角色某个卡包的卡，会在卡框上边缘显示**卡包名**（白字深色描边），在局内、奖励、图鉴和卡池视图中都会显示。

## 右上角卡包按钮

局内右上角有卡包按钮。悬停列出本局卡包；点击查看**本局牌池**（不含初始牌；按卡包 → 稀有度 → 名称排序）。用 ✓ 或 Esc 关闭。

## 图鉴

选中卡包角色的筛选时，图鉴显示其全部卡包卡牌（含原版卡）并在卡面显示包名，侧栏新增：

- **卡包**排序按钮；
- **卡包筛选**下拉框（只列出该角色的卡包）。

搜索框也可以输入卡包名。

## 设置

「设置 → 游戏设置 → 卡包大师」（可折叠）：

| 选项 | 含义 |
|---|---|
| 统一卡框 | 卡包卡使用卡包角色的卡框和能量图标。 |
| 允许多个"无"槽位 | 允许多个「无」（卡池很小时有风险）。 |
| [开发] 解锁全部卡包 | 忽略角色 mod 的解锁规则。 |
| [开发] 跳过选包 | 三选一随机决定，不显示选包界面。 |
| [开发] 宽松选包 | 见[候选规则](#候选规则)。 |

保存在 `user://PackmasterLib/settings.json`。

## 存档

本局卡包数据（配置、已选卡包、剩余轮数、是否确认）保存在普通存档中的一个隐藏的局内修改器里，所以继续游戏和多人同步都能正常工作。该修改器对涅奥和顶栏不可见。

## 多人模式

每个玩家有自己的卡包。多人模式使用各角色的 `DefaultSlots`，三选一按种子确定性决定，不显示选包界面。

## 字体与语言

库的界面使用游戏的 `MegaLabel` 和按语言的字体替换，中日韩等文字显示正确（字体 mod 也能生效）。界面文本覆盖游戏全部 16 种语言；卡包名和描述由角色 mod 提供。

## 自动测试（VanillaPacks）

VanillaPacks 包含一个像玩家一样操作的端到端测试（选人 → 出发 → 三轮选包 → 确认 → 涅奥，全程静音），以及大量单元检查：

```
SlayTheSpire2.exe --packmastertest --force-steam=off              # 窗口模式，截图保存到 user://packtest_*.png
SlayTheSpire2.exe --headless --packmastertest --force-steam=off   # 无头模式
```

然后在游戏日志中搜索 `PackmasterLib-AutoTest`，最后一行为 `RESULT: <n> checks, <m> failures`。
